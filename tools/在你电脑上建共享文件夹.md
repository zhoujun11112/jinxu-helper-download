# 在你自己电脑上建一个共享讨论文件夹

目标：你电脑上有一个真实文件夹，Claude 写的东西自动出现在里面，你放进去的东西 Claude 立刻看到。

---

## 方式一：GitHub Desktop（不用命令行，推荐）

1. 装 **GitHub Desktop**（https://desktop.github.com），用你的 GitHub 账号登录。
2. 菜单 `File → Clone repository`，选 `zhoujun11112/jinxu-helper-download`，
   本地路径随便挑，比如 `文档/短剧讨论`。
3. 克隆完成后，在右上角的分支下拉框里切到分支：
   `claude/japan-ai-drama-localization-zb42vp`
4. 打开那个文件夹，你会看到：
   ```
   docs/japan-ai-short-drama/
   ├── 01-adversarial-review.md          ← Claude 的评审报告
   ├── exchange/
   │   ├── R01-claude-to-gpt.md          ← Claude 的第1轮发言
   │   ├── PROTOCOL.md                   ← 讨论规则与时间约定
   │   └── inbox/                        ← ★ ChatGPT 的回复放这里
   ```

**每轮怎么用：**
- **收 Claude 的**：点 GitHub Desktop 左上角 `Fetch origin` → 新文件直接出现在文件夹里。
- **发给 Claude**：把 ChatGPT 的回复存成 `R01-gpt-to-claude.md` 放进 `inbox/` 文件夹 →
  回到 GitHub Desktop，左下角填一句话 → 点 `Commit` → 点 `Push origin`。
  Claude 那边 30 秒内自动发现，立刻开始写下一轮。

## 方式二：自动同步脚本（放进去就自动发，连按钮都不用点）

先克隆一次（终端里执行）：

```bash
git clone -b claude/japan-ai-drama-localization-zb42vp \
  https://github.com/zhoujun11112/jinxu-helper-download.git ~/短剧讨论
```

然后启动同步，**保持这个终端窗口开着**：

- **macOS / Linux**
  ```bash
  cd ~/短剧讨论 && bash tools/sync-folder.sh
  ```
- **Windows PowerShell**
  ```powershell
  cd $HOME\短剧讨论 ; powershell -ExecutionPolicy Bypass -File tools\sync-folder.ps1
  ```

跑起来之后：
- Claude 写的新文件**自动出现**在你文件夹里（终端会打印 `⬇ 收到 Claude 的新文件`）；
- 你把 ChatGPT 的回复存进 `docs/japan-ai-short-drama/exchange/inbox/`，
  **15 秒内自动发送**给 Claude（终端打印 `⬆ 已发送给 Claude`），你什么都不用点。

停止：按 `Ctrl+C`。

---

## 关于 ChatGPT 那一头

这个文件夹解决的是**你和 Claude 之间**的自动化。ChatGPT 那边仍然需要你两个动作：

- **给它看**：把文件夹里的 `.md` 文件直接拖进 ChatGPT 对话框（它读上传的文件没问题）。
  或者让它自己联网读 GitHub 链接——已经验证它能读到。
- **收它的**：让它把回复输出成 `R01-gpt-to-claude.md` 文件，你下载后拖进 `inbox/` 文件夹。

原因：ChatGPT 没有写入你硬盘或写入 GitHub 的能力，只能把内容显示在对话框里。
**唯一能彻底免掉这一步的办法**是在 ChatGPT 的 agent 模式里登录一次 GitHub，
让它自己提交到 `inbox/`——那样整条链路就全自动了。

---

## 文件命名规则

```
exchange/R01-claude-to-gpt.md        Claude 第1轮  →  给 ChatGPT
exchange/inbox/R01-gpt-to-claude.md  ChatGPT 第1轮回复  →  给 Claude
exchange/R02-claude-to-gpt.md        Claude 第2轮
exchange/inbox/R02-gpt-to-claude.md  ChatGPT 第2轮回复
...
```

轮次号必须对齐。总共跑 4 轮，第 4 轮收敛成一页可执行结论（见 `PROTOCOL.md` 第六节）。
