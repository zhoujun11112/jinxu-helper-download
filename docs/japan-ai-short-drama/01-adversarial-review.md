# 日本市场AI短剧方案 · 对抗式评审报告

> 评审方式：按方案第十六节要求，分别以**日本编剧、制片人、技术负责人、版权顾问、平台运营负责人**五个角色进行对抗式评审（不是补充建议，而是挑毛病），随后逐条回答18个问题，最后给出修订后的更低成本验证方案。
>
> 时效性说明：本报告中涉及的产品名称、价格、平台政策等事实性信息基于2026年初的认知，AI视频行业迭代极快，执行前请按文末"待核实清单"逐项复核。

## 第一部分 · 总体结论（先说结论）

### 同意的核心判断

方案的大方向判断力很强，以下几点全部同意，不再重复论证：

- 不先买高端显卡，前期全用云端API；
- 70%现成工具 + 30%自建规则/资产/审核；
- 不做直译，做社会语境重构（第四节的元素映射表整体专业水准很高）；
- 不一次生成整集，逐镜头生成；
- 日语母语审核不可省；
- 先小规模测试，分三阶段建设；
- "验收标准是像不像日本故事，不是画面华不华丽"——这句话是全方案最值钱的一句。

### 三个结构性缺口（比任何工具选型都重要）

1. **商业闭环缺失**。方案通篇没有回答"钱从哪来"。TikTok/YouTube Shorts免费播放的广告分成在日本是每次播放约0.01–0.1日元的量级，12分钟的测试内容收入约等于零。测试买到的是**数据**，不是收入。必须在开工前预设"数据好了卖给谁"（详见平台运营角色评审）。
2. **成本模型缺失**。方案说"测算真实成本"，但没有预算表、没有排期、没有团队配置、没有投放预算。"测算成本"本身也需要预算。返工率（抽卡率）会让真实成本达到理论成本的2–4倍，这一点被系统性低估（详见制片人角色评审）。
3. **目标观众未定义**。全篇没有一句话说"做给谁看"。日本短剧付费主力是30–50代女性。这一个定义会反过来改写题材优先级、男女主设定、投放策略和配音风格。第一部样片按现在的写法是"职场剧"，但它必须被明确写成**女性向**职场剧才成立。

### 一个方案没有提到、但应该成为核心逻辑的优势

AI流水线相对实拍的真正杀手锏不是便宜，而是**可以数据驱动地重拍**：哪一秒观众流失，就重新生成哪一个镜头，48小时内换掉，再看数据。实拍剧做不到这件事。建议把"逐镜头留存归因 → 定点重生成"写进流水线的核心循环，这是这套模式相对翻译剧和实拍剧的差异化叙事，融资和谈合作时也是最有说服力的一句话。

## 第二部分 · 五角色对抗式评审

### 角色一：日本编剧 ——「这个剧本在日本社会里不成立的地方」

**异议1：反派职位"女组长"是一个会当场穿帮的用词。**
日语里「組長」首先让人想到黑帮头目，公司办公室里不存在"组长"这个叫法（制造业车间有「組長」，但那是工厂语境）。办公室语境应该是「係長」「主任」「チームリーダー」。讽刺的是，方案第八节的知识库明确要防"低级错误"，而样片人设里就埋着一个。这恰好证明：**知识库第一批要建的不是文化常识，而是职位词汇表和称谓表**——这类错误AI改写时批量复发。

**异议2："被开除的合同员工"在日本劳动法下站不住。**
日本解雇规制极严，合同期内解雇合同员工需要相当极端的事由，观众里任何一个上班族都会觉得假。日本社会里真实且更冷的对应物是**「雇止め」（合同到期不续签）**：会议室里，人事微笑着说「次回の更新はございません」——礼貌、合规、无法反抗。这比"开除"更日本、更压抑、爽点爆发时也更强烈。第1集的钩子应该改成雇止め通知，标题也随之调整，例如日式长标题：《クビにされた派遣の私、実はこの会社の"顔のないエース"でした》（日本网文式长标题在短视频封面上有效）。

**异议3："公司关键算法的匿名原作者"与日本《特许法》第35条职务发明制度冲突。**
在职期间开发的核心算法，专利权利归属公司（职务发明预约承继），"她私下拥有公司核心专利"不成立，懂行的观众会出戏。三个修法建议，任选其一，戏剧性反而更强：
- **署名剽窃线**：她是真实发明人，但係長在专利申请和学会论文上抹掉了她的名字（冒认申请/发明人名誉权）。反转证据=代码提交记录、实验笔记、内部邮件——全部是屏幕特写镜头，AI制作成本几乎为零；
- **入职前作品线**：算法核心是她入职前以匿名ID发布的开源项目，公司产品深度依赖该项目，她随时可以证明自己是维护者；
- **外部匿名顾问线**：公司花大价钱咨询的"匿名技术顾问"就是被雇止め的她本人。

**异议4：警惕"克制"的过度矫正。**
方案说日本版要"情绪克制、信息逐步揭露"，方向对，但存在把剧写闷的风险。日本本土爆款短剧和网文（婚约破弃、追放ざまぁ、サレ妻复仇）的爽点密度并不低，**克制的是表达方式，不是节奏**。60秒内仍然需要每15–20秒一个转折；日本观众要的是"礼貌的表面下刀刀见血"，不是"礼貌"。建议给每集定硬性节拍规则：0–3秒冲突预告、每集至少1次信息增量、结尾悬念，这些和国内短剧完全一致。

**异议5：缺少"内心独白"这个日本武器。**
日本女性向内容（TL漫画、纵向短剧、サレ妻系视频）高度依赖**モノローグ（内心独白旁白）**。它同时解决三个问题：情绪克制下的情感传达、日语台词过长（敬语句子说完要5–8秒）、以及口型同步成本（独白盖在表情镜头上，根本不需要口型）。强烈建议女主视角独白成为叙事主干。

**异议6：每一集都必须能被单独刷到。**
TikTok的分发是乱序的，观众可能先刷到第5集。每集开头需要3秒"前情速览"字卡+独立成立的钩子。方案的"第3集暗示、第6集反转、第12集大反转"结构没问题，但要加上这条单集自洽原则。

**小修正**：34岁的"开发本部长"偏年轻，中型公司可解释为中途入社的创业元老或执行役员，人设里补一句即可；男主第一人称建议「僕」（理性温和），係長对女主用慇懃無礼的敬语（表面客气的羞辱是日本反派的标准武器），女主对外「私」、独白可降为更口语的表达——这类规则正是方案第八节称谓表该管的事。

**编剧结论**：题材方向可做，人设需按上述三处硬伤修复；把目标观众明确为30–50代女性，感情线和独白按女性向标准写。修复后内容质量可从3分升到4分。

### 角色二：制片人 ——「这个案子我现在不敢批预算，因为根本没有预算」

**异议1：没有预算表。** 我按12集×60秒（约12分钟成片）补一张试产预算（人民币，2026年初价格量级，需复核）：

| 项目 | 估算 | 备注 |
| --- | --- | --- |
| 剧本（AI初稿+人工定稿） | 2,000–5,000 | 含12集分集剧本+分镜脚本 |
| 日语母语监修（2轮） | 1,500–4,000 | 约3万–8万日元，兼职编辑行情 |
| 角色/场景定妆资产 | 500–1,500 | 文生图+角色LoRA训练 |
| 视频生成API | 3,000–7,000 | 约120–160镜头×3–4抽，按可灵/Seedance档位 |
| 配音 | 500–1,500 | ElevenLabs Pro或同级日语TTS月费 |
| 音乐音效曲库 | 200–500 | Artlist/Epidemic/AudioStock订阅 |
| 剪辑/字幕/封面 | 人力 | 60–100工时，最大的隐性成本 |
| **投放测试** | **5,000–20,000** | 方案里完全没有这项，见异议4 |
| **现金合计** | **约1.3万–4万** | 另加约1.5–2人×6–8周人力 |

**异议2：返工率被系统性低估。** "每镜头3–8秒单独生成"说得轻松，但跨镜头人物一致的**可用率**（抽卡通过率）现实中在25%–50%之间浮动，手部、多人同框、转身镜头更低。所有API成本按理论值×3做预算，是行规不是悲观。

**异议3：没有排期。** 现实排期约6–8周，不是"跑通一下"：
- 第1–2周：剧本+监修定稿，同时做角色定妆；
- 第2–3周：**3镜头技术验收**（同一角色×3场景×3镜头，验一致性和口型）——这是第一个go/no-go门，不过关就换风格或换形式，此时只花了不到3,000元；
- 第3–5周：生成+剪辑前3集，投放，看数据门；
- 第5–8周：达标则补齐9集，不达标则回炉。

**异议4：0粉账号的自然流样本又小又随机，测不出结论。** 必须配5,000–20,000元投流买显著样本，否则"3秒留存"的数字方差大到没有决策价值。这笔钱比多生成100个镜头重要。

**异议5：12集只能测留存，测不了付费。** 翻译剧的付费墙通常设在第8–12集之后、总量60–100集的结构里。向平台方推销时，对方要的是"百集规模下的单集成本模型"，试产期就要同步产出这张推演表（试产单价×规模化系数），否则数据再好也谈不动商务。

**异议6：团队最小配置没写。** 最小可行是2.2人：1名制片兼投放、1名双语编剧（会用AI）、1名AIGC生成师兼剪辑、外包0.2名日语监修。一个人全兼的方案会死在剪辑工时上。

**制片人结论**：批准试产的前提是补齐预算表、排期、两道go/no-go门（3镜头技术验收、3集数据验收）和投流预算。总盘子控制在4万元现金+8周以内，我可以签字。

### 角色三：技术负责人 ——「一致性的方法论缺失，流程顺序有一处是反的」

**异议1：方案只解决了"镜头内一致"，没解决"跨集一致"。** 绑参考图只能保住单镜头。12集×120个镜头、不同光线场景下同一张脸不漂移，靠的是**关键帧先行的图生视频流水线**：
1. 定妆九宫格 → 为主角训练**角色LoRA**（Flux/SDXL级别的文生图模型）；
2. 每个镜头先用LoRA+场景底图生成**首帧/尾帧关键帧**（廉价、可抽卡、可人工筛）；
3. 关键帧通过验收后，再走图生视频（首尾帧模式）；
4. 每镜头登记台账：prompt、seed、模型版本、抽数、可用标记、成本。
纯文生视频或单参考图直出，跨集必漂。另外**锁死模型版本**——视频平台升级模型会导致同一prompt人脸变化，这是真实发生过的事故类型。

**异议2：流程顺序反了——必须音频先行。** 方案的流水线是"生成视频→配音"。日语敬语台词很长（一句道歉5–8秒），先出画面再配音必然对不上节奏。正确顺序：**分镜脚本带台词秒数 → 先生成配音 → 按音频时长剪出节奏样带（animatic）→ 按秒数生成画面**。口型同步只在近景做，中远景/过肩/背影/独白盖表情镜头全部规避口型，能省掉一半口型成本。

**异议3：双人同框对话是成本黑洞。** 同框双人的一致性和口型双重崩坏，改用正反打（shot-reverse-shot）单人镜头拼剪，这也是实拍剧的标准做法，观众毫无违和。

**异议4：画面内的日文文字一律禁止AI生成。** AI渲染的日文招牌/工牌/文件是乱码重灾区（方案的视觉禁错表提到了文字，但没给对策）。对策：所有画面内文字（手机屏幕、邮件、专利文件、门牌、工牌）一律**后期贴字或用UI截图素材插入**。顺便说，本剧的关键证据都是屏幕和文件——这些镜头用截图制作成本约等于零，还最真实。

**异议5：工具选型按镜头类型分层，不是选一家。**（2026年初认知，需复核各家最新版本）
- 批量叙事镜头：可灵2.x / Seedance / Vidu（性价比+参考图/多主体能力）；
- 关键情绪镜头：Veo 3.x / Sora 2 级别（贵，只给每集1–2个"money shot"）；
- 动画风备选：Vidu / PixVerse 系；
- 日语TTS：ElevenLabs v3、MiniMax语音、CoeFont（日本公司、声库授权干净）、にじボイス（动画向）——选型时把"商用授权+声库合规"当硬条件（详见版权评审）；
- 口型：可灵口型/Veo原生音频/专用lip-sync工具，只做近景。

**异议6：n8n/Dify放二阶段是对的，但一阶段有四件不性感的必做事**：文件命名规范（例：`EP03_S02_C05_v3`）、镜头台账表、云盘目录树、每日成本汇总。知识库初期就是一个Notion/多维表格+prompt片段库，**不要建RAG系统**，12集的规则量用检索纯属过度工程。

**异议7：被低估的技术细节**：API限流与排队（跑批放夜间）、1080p放大与9:16安全区（TikTok和Shorts的UI遮挡区不同，字幕位置要双版本或取交集）、多平台交付规格、素材备份。

**技术负责人结论**：技术上完全可行，但要按"LoRA+关键帧+台账+音频先行"重排流水线；先花3,000元做3镜头技术验收再谈量产。

### 角色四：版权顾问 ——「第一部不要买剧本，声音是日本市场最大的雷」

**异议1：第一部用原创剧本，不是"优先购买版权"。** 方案第十四节的风险认知全部正确（保留结构+反转+人设=改编作品；AI改写不消除风险），但结论应该更进一步：试产阶段买版权是**花钱买风险和谈判周期**。原创12集职场剧的创作成本远低于授权谈判成本，且数据资产完全归自己。验证成功后再买爆款改编权，且合同必须包含：
- 日本区域独家**改编权+二次的著作物利用权**（不是翻译权）；
- **明示允许AI方式制作**（部分版权方合同已开始明文禁止AI改编，这一条会成为常见坑）；
- **著作者人格权不行使特约**（中国法下的保护作品完整权/日本法下的同一性保持权——深度本地化必然大改原作，没有这条随时被叫停）；
- 续集/衍生/剧本二次开发权、分发平台范围、期限、分成审计条款。

**异议2：声音克隆是日本市场公关和法律双重雷区，方案只用一行带过。** 2024年起日本声优界发起了against无断AI声音生成的联名运动，社会情绪敏感度远超中国市场。红线三条：**只用平台官方商用授权声库；禁止用任何真人音频克隆；禁止以"像某声优/艺人"作卖点**。日本本土授权干净的选择（如CoeFont等取得本人授权的声库）在公关层面更安全。将来若上真人配音，签的授权书里要明示"允许AI辅助处理/不用于训练克隆"的边界。

**异议3：AI人脸的"撞脸"风险要建自查流程。** 生成模型见过大量日本艺人脸，定妆产出后对主角脸做反向图搜自查；prompt中禁止出现任何真人姓名。日本的肖像权/パブリシティ権判例活跃，艺人事务所维权积极。

**异议4：音乐与字体是最容易忽视的确定性成本。** BGM用商用曲库订阅（含日本本土的AudioStock），**不要用来源存疑的AI生成音乐**（头部AI音乐平台在多地涉诉，风险未定价）；TikTok商业音乐库仅限投放素材场景。字体商用授权确认（免费安全线：Noto Sans JP/源ノ角/M+系）。片中出现的公司名、logo、产品名全部虚构，注册商标检索一遍。

**异议5：平台AI标识按"必须标"执行，并把它变成定位。** TikTok对写实类AIGC强制标注、YouTube要求披露合成内容（政策措辞随时更新，执行前复核）。日本2025年通过的AI相关立法是促进型框架，暂无硬性内容标注法定义务，**但平台规则就是事实上的法律**。战略建议：与其被扒出来，不如公开打"AIショートドラマ"标签——隐瞒被发现的成本远高于标注的流量损失。

**异议6：内容尺度速查。** 不伦/复仇题材在日本是主流，完全可做；注意：未成年人相关描写从严；医疗题材不做具体疗效断言；投放素材受景品表示法+ステマ规制约束（2023年施行，"用户好评"必须真实）；远期自建App卖币触发资金决济法（前払式支払手段）与特商法义务，试产期无关但要知道在那里。

**版权顾问结论**：试产期风险完全可控，前提是：原创剧本、授权声库、曲库BGM、虚构商号、主动标AI。最大的隐性雷是声音，最常见的坑是未来买剧本时合同缺AI许可和人格权条款。

### 角色五：平台运营负责人 ——「数据好了卖给谁？这一页是空白的」

**异议1：先定买家，再定验收标准。** 免费平台播放≈零收入，这次测试的产出必须是**能卖的东西**，可能的路径按优先级：
- **路径A（首选）：成片授权/内容供应给现有短剧App**。日本市场上既有中国系平台（DramaBox、ShortMax、ReelShort、TopShort等）大量采购和委制内容，也有本土平台（BUMP等）。**试产期就应该带着前3集去接触2–3家的内容采购口**，把对方的采购标准（时长、集数、题材、质量线、价格区间）变成你的验收标准。这一步成本为零，信息价值全案最高。
- 路径B：账号资产化——粉丝积累后向自有渠道/会员导流（远期）。
- 路径C：品牌定制剧（AI短剧的成本结构对广告主有吸引力）。
方案十三节"第三阶段形成平台"之前，缺了"第2.5阶段：把内容卖出去"。

**异议2：竞争格局一段都没写。** 2024–2026年日本短剧供给爆发：中国系App用翻译剧+本土委制剧大量投放，本土厂牌（BUMP、ごっこ倶楽部等）做原创且质量线高。翻译剧已证明"日本用户愿意为短剧付费"，其差评集中在"不自然/翻译腔"——这正是本方案的定位空间，但必须写成明确的定位句：**质感≥翻译剧配音版，成本≤本土实拍的1/5，产能和迭代速度×10**。三个数字都要在试产期拿到证据。

**异议3：KPI没有数值门槛，等于没有KPI。** 方案十二列了指标但没给判据。初始门槛建议（投放后用同类目账号基准校准，数字本身不神圣，"事先写下判据"才神圣）：
- 3秒留存 ≥65%；60秒单集完播 ≥40%；
- EP1→EP2点击 ≥35%；EP1→EP3 ≥20%；
- 关注转化 ≥1.5%；
- 负面评论中"AIっぽい/不自然"类占比 <10%；
- 未达标 → 停止扩产，回炉题材或形式，而不是"再做几集试试"。

**异议4：投放与发布策略补全。**
- 平台：**TikTok日本区为主战场**（短剧观众已被教育、冷启动最快），YouTube Shorts同步双发（30代以上覆盖+搜索长尾+合集功能），Instagram Reels第三，LINE VOOM暂缓；
- **日本特有：X（Twitter）切片传播**。日本X生态强势，サレ妻/スカッと类文字文化就发源于此，剧情切片+话题标签在X上的二次传播是其他市场没有的红利；
- 节奏：日更1–2集连发（追更习惯），用合集/プレイリスト功能，每集独立钩子标题（由监修把关日文）；
- 时段：通勤7–9时、午休12时、晚间21–24时（JST）；
- 评论区：日本用户评论少而精，差评信息密度极高，逐条人工读，"不像日本人"类评论直接进知识库。

**异议5：AI标注的运营面。** 公开挂"AIショートドラマ"厂牌定位：一方面规避被扒风险（见版权评审），另一方面日本市场对技术实验有novelty好感，AI本身可以是话题营销的一部分。但底线是内容先成立——AI是修饰语，不是卖点本体。

**异议6：善用AI剧独有的运营武器。** 逐秒留存曲线归因到具体镜头/台词 → 重生成该镜头 → 48小时内替换重发。把"数据驱动重拍"做成运营SOP，这是对实拍内容的代差优势（与总体结论呼应，这里是落地动作）。

**平台运营结论**：在"先接触2–3家内容采购方、KPI门槛前置、配投流预算"三件事补齐之前，这个测试测不出商业结论，只能测出"有没有人看"。补齐后，12集试产是一个合格的最小商业实验。

## 第三部分 · 18个问题逐条回答

**1. 日本短剧市场目前最值得切入的题材？**
付费主力是30–50代女性，最强的三个类型带：①不伦/背叛×制裁（サレ妻系——日本有成熟的受众文化和词汇体系）；②被轻视女性的身份/地位反转（婚约破弃、追放ざまぁ的现代职场变体）；③溺爱×身份差（御曹司系，TL漫画传统，对应"霸道总裁"的本土原生形态）。方案的方向一、二正好落在②和①上，选得对。

**2. "职场身份反转"适合做第一部吗？**
适合，附三个条件：按编剧评审修复三处硬伤（組長→係長、解雇→雇止め、专利归属→署名剽窃）；明确写成女性向（女主视角+独白+轻感情线）；节奏不因"克制"降密度。它的场景可控性确实是AI制作的最优解。

**3. 第一部做3集、12集还是30集？**
写完12集剧本（写作便宜），**先制作3集**投放，过数据门再补齐12集。不做30集——12集已足够测留存曲线，30集在没验证前是纯粹的浪费。注意12集测不了付费（见制片人异议5），这是已知边界，不必为此加集数。

**4. AI真人风、动画风、真人拍摄，哪种适合验证？**
用"3镜头技术验收"来决定，不要凭偏好：同一角色×3场景先跑真人写实风，若一致性+口型达标 → 真人风（对接短剧App采购必须是实写系）；不达标 → 转2.5D/风格化写实（日本观众对动画审美接受度全球最高，恐怖谷风险和一致性成本都低一档）。真人实拍不是本项目的赛道，但报价要心里有数（日本实拍约为AI成本的5–10倍），它是你的质量对标线。

**5. 日本观众对AI人物和AI配音的接受度？**
分层看：普通刷流用户——故事成立+标注清晰就接受，质量差才排斥；创作者/粉丝社群——对AI敏感甚至敌对（插画圈反AI情绪、声优界反无断克隆运动），不要在其地盘挑衅；配音比画面更容易暴露AI（棒読み感），日语的情绪韵律是TTS弱项，所以配音要人工逐句验收，规模化后主角可上真人声优（日本兼职声优行情并不贵）。总体：接受度是"及格线以上不敏感，及格线以下极其严苛"。

**6. 哪些中国短剧冲突在日本最容易水土不服？**
当众羞辱类（扇耳光、撕衣、下跪）、金钱炫耀类（甩钱、包场、"这层楼我买了"）、秒跪认错类（反派瞬间态度反转）、神医当场救人类、以及一切"大声吵赢"的冲突——日本语境里声音大=输。替换逻辑方案第四节的表已经给对了：证据、处分、社会性死亡、谢罪。补一条：威胁性台词（"你给我等着"）直译即穿帮，日语的威胁是敬语说得越标准越冷。

**7. 日本版剧本最需要本地人员审核的环节？**
两道人工门：**剧本定稿前**（台词自然度、敬语/称谓/男女用语、职场流程真实性、人物反应是否"中国化"）和**成片终审**（配音语调、字幕自然度、画面禁错）。中间环节可以AI化，这两道门不能。另外台词必须"日语原生写作"——用中文大纲直接写日语台词，禁止中文台词逐句翻译，翻译腔九成产生在这一步。

**8. 有没有比PopShort、LTX、可灵、Vidu、Runway更合适的平台？**
思路从"选平台"改成"按镜头类型分层组合"（见技术评审异议5）：批量镜头用可灵/Seedance/Vidu档，关键镜头用Veo/Sora档，关键帧用Flux+LoRA，日语TTS把CoeFont等日本本土授权声库纳入对比。分镜/资产管理层面LTX类可用，但12集规模用多维表格+云盘就够，先别为工具付费。所有具体版本以执行时实测为准——这个市场每季度洗牌。

**9. 日本本土有没有成熟的短剧SaaS或发行渠道？**
发行渠道有：本土App（BUMP等）、中国系App日本区（DramaBox/ShortMax/ReelShort/TopShort等）、以及TikTok/YouTube/X的免费分发；本土的短剧**制作SaaS基本不存在**——这正是方案"30%自建"部分的长期价值所在。行动建议：把渠道名单做成商务接触清单（见运营评审异议1），SaaS空白留作第三阶段的选项而非现在的目标。

**10. 合理单集长度、集数、付费模式？**
市场主流：翻译/委制剧约1.5–2分钟×60–100集，前8–12集免费后单集解锁（每集约合几十至一百多日元）或"待到免费"模式，日本用户ARPU高、对追更付费接受度已被验证；本土原创多为1–3分钟×20–40集。测试期：60–90秒×12集免费投放是正确规格；商业化规格向"2分钟×60+集"靠拢，谈采购时按这个规格报产能。

**11. 首批测试选哪个平台？**
TikTok日本区为主、YouTube Shorts同步双发、X做切片二次传播（日本特有红利）、IG Reels顺带、LINE VOOM暂缓。配投流预算5,000–20,000元人民币买显著样本，纯自然流测不出结论。

**12. 一分钟AI短剧的合理成本范围？**
三个数字（2026年初量级，含返工，需按执行时价格复核）：纯API现金成本约300–1,000元/分钟；试产期综合成本（含人工）约2,000–6,000元/分钟；规模化目标应压到800–2,000元/分钟。对标线：日本本土实拍约1万–3万元/分钟。若综合成本长期高于8,000元/分钟，AI路线相对实拍失去意义，应止损或转形式。

**13. 哪些步骤自动化，哪些必须人工？**
可自动化：剧本拆解、日本化初稿、提示词生成、文件命名、格式转换、字幕初稿、成本台账、任务流转。必须人工：日语终稿、定妆选卡、每镜头验收（一致性/手/文字）、剪辑节奏、成片终审、评论区阅读。判据一句话：**生成可以自动，判断必须人工**。自动化时点也认同方案的分阶段——第一部全人工跑通，第二部才值得搭n8n。

**14. 如何建立稳定的人物一致性和声音一致性？**
人物：定妆九宫格→角色LoRA→关键帧先行→图生视频（首尾帧）→镜头台账记录prompt/seed/模型版本→锁模型版本。场景：底图+固定机位描述模板。声音：每角色固定voice ID+参数写入角色卡，锁TTS版本，建30秒"声音样本库"作为每集验收基准；口型只在近景做，独白和正反打规避大部分口型需求。一致性不是某个工具的功能，是一套**资产+台账+验收**的纪律。

**15. 先买国内剧本版权，还是原创日本剧本？**
第一部：**原创**（快、便宜、干净、数据归自己）。验证后：买头部爆款的日本区改编权+与版权方联合出海（对方出剧本库和已验证数据，你出本地化产能和渠道）双轨谈。买时合同四要件：日本区独家改编权、明示允许AI制作、著作者人格权不行使特约、续集衍生权（详见版权评审异议1）。

**16. 日本市场的版权/声音/肖像/音乐/平台合规风险清单？**
按风险×概率排序：①声音克隆（声优界敏感度极高，只用授权声库，禁真人克隆）；②改编权（结构+反转+人设相似即构成改编，AI改写不消权）；③AI脸撞脸艺人（定妆反搜自查，prompt禁真人名）；④音乐（曲库订阅，不用来源存疑的AI音乐）；⑤平台AI标注（TikTok/YouTube强制或要求披露，主动标）；⑥字体/商标/虚构商号；⑦投放合规（景表法+ステマ规制）；⑧远期自建App的资金决济法/特商法/APPI。日本无硬性AI内容标注法（促进型立法框架），但平台规则=事实法律。

**17. 方案里被明显低估的成本、难点、风险？**
七项：①返工率（真实成本=理论×2–4）；②剪辑/QC人工工时（最大隐性成本）；③投流预算（完全缺失）；④商业闭环（测试≠收入，无买家假设）；⑤跨集一致性方法论（只解决了镜头内）；⑥竞争窗口（翻译剧价格战+本土原创质量线上移，AI剧的novelty窗口在收窄，节奏要快）；⑦母语监修的迭代轮数（一轮改不完，预算按两轮起）。外加一个认知风险：12集数据好≠商业模式成立，中间还隔着采购谈判和百集产能证明。

**18. 更低成本、更快验证的替代方案？**
见第四部分"三级火箭"。核心思想：**先用几乎零成本的形式验证剧本和钩子，再把已验证的剧本升级成AI视频**——不要用最贵的形式去测最不确定的东西。

## 第四部分 · 修订版验证方案（三级火箭）

每一级设kill标准，任何一级失败，损失不超过上一级投入。

### 第0级 · 题材假门测试（1–2周，预算 <1万元）

- 三个题材各做一支60–90秒**预告片**：职场身份反转 / 主妇财产反击 / 京都老铺继承（预告片可用少量AI镜头+字卡+配音+BGM拼成，单支成本几百元）；
- TikTok日本区投流A/B，比较3秒留存、完播、关注转化、评论情绪；
- 同步把胜出题材的12集剧本写完并完成母语监修（写作便宜，不等待）；
- kill标准：三支预告全部3秒留存<50% → 题材库回炉，不进入下一级。

### 第1级 · 声漫版剧情验证（2–3周，预算3千–8千元）

- 胜出题材做**声漫版12集**：静止画/轻动效+日语配音+字幕+独白（日本市场对该形式高度熟悉——スカッと系、漫画动画类频道以极低画面成本长期收获大流量，观众对画面简陋容忍度已被验证）；
- 全量投放测完整留存曲线，逐句归因流失点，修剧本；
- 这一级同时完成：角色定妆资产、声音ID库、称谓/敬语表实战校验；
- kill标准：EP1→EP3追看<15%且修脚本一轮后无改善 → 剧本层问题，不进入视频级。

### 第2级 · AI视频版（4–6周，预算1.5万–3.5万元）

- 先做**3镜头技术验收**（真人写实风，不过关转2.5D风）；
- 用已验证的剧本+已定妆的角色生成前3集 → 投放过数据门（KPI见运营评审异议3）→ 补齐12集；
- **并行商务动作**：带前3集接触2–3家短剧App内容采购口，拿到采购标准和意向价格；
- 产出四件套：12集成片、单分钟成本模型（含百集规模推演）、留存数据包、采购方反馈。

### 三级总投入

现金约3万–5万元，周期10–14周，每一级都产出独立可用的资产（题材数据 / 已验证剧本+声音资产 / 成片+成本模型+商务反馈）。对比原方案直接进入12集AI视频制作：总额相近，但把最大的不确定性（题材和剧本）用最便宜的形式提前消化了。

## 第五部分 · 立即可执行的两周行动清单

1. 定义目标观众一句话（建议：30–50代日本女性，通勤和睡前刷TikTok/Shorts）并写进所有文档头部；
2. 按编剧评审修复样片三处硬伤（係長/雇止め/署名剽窃线），标题改日式长标题；
3. 建立四张表：职位称谓表、角色卡（含声音ID）、镜头台账模板、成本日报模板；
4. 写三支预告片脚本并完成母语监修（第0级启动）；
