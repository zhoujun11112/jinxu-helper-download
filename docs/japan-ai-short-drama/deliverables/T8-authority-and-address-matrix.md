# T8 · 职权映射表与称谓矩阵

交付编号 T8（自主补充，非任务指派）
目的：**压掉日语监修的返工轮数**。监修单价是成本第三驱动（敏感度 +9.6%），而监修工时主要消耗在反复纠正同一类结构性错误，不是逐句润色。这张表在剧本进入监修前就把结构性错误挡住。

---

## 第一部分 · 职权映射表

采纳 ChatGPT 在 R01·A1 的修正：不做"中日职位词汇对照"，做**职权维度映射**。中国短剧里的"组长/主管/总监"必须先拆成职权，再映射到日本职级。

### 映射的五个判定维度

给中方原职位逐项打勾，再查表落位：

| 维度 | 问题 |
|---|---|
| D1 人事评价权 | 是否给下属打考评、影响其晋升 |
| D2 预算审批权 | 能否独立批经费，额度量级 |
| D3 管理监督者 | 是否属于劳基法意义上的管理监督者（影响加班费与工会资格） |
| D4 正式职级 or 项目角色 | 是组织图上的职位，还是项目临时角色 |
| D5 企业类型 | 传统大企业 / 创业公司 / 制造业 / 老字号 |

### 落位表

| 日文职位 | D1人事权 | D2预算权 | D3管理监督者 | 典型年龄 | 适用企业 | 备注 |
|---|:---:|:---:|:---:|---|---|---|
| `主任` | ✗ | ✗ | ✗ | 28–35 | 通用 | 最低阶"有头衔无实权"，本剧反派的合理落点之一 |
| `係長` | △ 建议权 | △ 小额 | ✗ | 30–40 | 传统企业 | 有下属但仍是被管理者；**本剧反派推荐职位** |
| `課長代理` | △ | △ | ✗ | 33–42 | 传统大企业 | 課長的候补，权力焦虑感强，适合写"急于抢功" |
| `課長` | ✓ | ✓ | ✓ | 35–48 | 通用 | 真正的管理层门槛 |
| `次長` | ✓ | ✓ | ✓ | 40–50 | 传统企业 | 部長与課長之间，非所有公司都设 |
| `部長` | ✓ | ✓✓ | ✓ | 42–55 | 通用 | **男主职位**；34岁任部長偏年轻，需在人设里给理由 |
| `本部長` | ✓ | ✓✓ | ✓ | 45–55 | 大企业 | 统辖多个部 |
| `執行役員` | ✓ | ✓✓✓ | ✓ | 45–60 | 大企业 | 若男主34岁，用此职位+中途入社/创业元老更可信 |
| `チームリーダー` | ✗ | ✗ | ✗ | 25–40 | 创业/IT | **项目角色而非职级**，与正式职级并存 |
| `プロジェクトマネージャー` | ✗ | △ | ✗ | 30–45 | IT | 同上 |

### 禁用词

| 禁用 | 原因 | 替代 |
|---|---|---|
| `組長` | 首义为黑帮头目；工厂车间班组长为次义，办公室不用 | `係長` `主任` `チームリーダー` |
| `部門経理` | 中文"经理"直译，日语无此用法 | `部長` `課長` |
| `総経理` | 中国企业职位，日企不用 | `社長` `代表取締役` |
| `董事長` | 同上 | `会長` `代表取締役会長` |
| `人事部长`直译为 `人事部長` 时需注意 | 本身没错，但中小企业常为 `総務部長` 兼管 | 按企业规模选 |

### 本剧落位（第一部样片）

| 角色 | 日文职位 | 判定依据 |
|---|---|---|
| 女主 | `有期契約社員`（非派遣） | 直接受雇于公司，第1–2次续约节点。**不写"派遣社員"**——派遣的雇主是派遣公司，剧情里"公司开除她"会立刻穿帮 |
| 男主 | `開発本部長` 或 `執行役員` | 34岁任本部長需理由：中途入社的技术负责人 / 创业元老。二选一必须在第1集用一句台词交代 |
| 反派 | `係長`（正社員） | 有下属、有建议权，但仍受課長管辖——正因为她自己也被压着，抢功动机才成立 |
| 老员工 | `主任`（正社員，50代） | 无实权，靠年功，是"沉默的目击者"的合理身份 |
| 人事 | `人事課長` | 通知雇止め的人必须有正式职权，否则那场戏不成立 |

## 第二部分 · 称谓矩阵

**行 = 说话人，列 = 被称呼者。**每个角色对每个人的称呼在全剧固定，这是 AI 批量生成中最容易漂移、也最容易被日本观众抓到的一项。

| 说话人 ↓ ＼ 对象 → | 女主 | 男主(本部長) | 反派(係長) | 老员工(主任) | 人事課長 | 女主朋友 |
|---|---|---|---|---|---|---|
| **女主** | — | `本部長` | `〇〇さん` | `〇〇さん` | `課長` | 名+`ちゃん` |
| **男主** | `〇〇さん` | — | `〇〇さん` | `〇〇さん` | `〇〇課長` | — |
| **反派** | 姓呼び捨て or `〇〇さん`（慇懃無礼） | `本部長` | — | `〇〇さん` | `課長` | — |
| **老员工** | `〇〇さん` | `本部長` | `〇〇さん` | — | `課長` | — |
| **人事課長** | `〇〇さん` | `本部長` | `〇〇さん` | `〇〇さん` | — | — |
| **女主朋友** | 名+`ちゃん` | — | — | — | — | — |

### 反派的称谓武器

反派对女主的称呼是全剧最重要的一个设计点。建议**分段变化**，让称呼本身成为剧情信号：

| 阶段 | 反派对女主的称呼 | 效果 |
|---|---|---|
| 第1–5集 | 姓 + 呼び捨て（不加さん） | 日本职场中对同事去掉 `さん` 是明确的轻视信号，比任何台词都狠 |
| 第6–11集 | 姓 + `さん`（态度突然客气） | 身份暴露后的恐惧，礼貌反而是慌乱 |
| 第12集 | 姓 + `さん` + 敬语过剩 | 慇懃無礼倒转，此时的过度礼貌是社会性死亡的开场 |

**这是"日本式打脸"的核心机制**：不靠扇耳光，靠称呼的一个音节变化。中国观众可能感受不到，日本观众一秒就懂。

### 第一人称固定表

| 角色 | 台词中 | 独白中 | 禁止 |
|---|---|---|---|
| 女主 | `私`（わたし） | `私`（可略口语化） | `あたし`（与克制人设不符）、`わたくし`（过于正式） |
| 男主 | `僕` | — | `俺`（与理性人设不符）；对客户场合可切 `私` |
| 反派 | `私` | — | 全剧不变，她的失控只体现在称呼和敬语，不体现在第一人称 |
| 老员工 | `私` / `わし`（若设定为60代） | — | 需与年龄设定一致 |
| 女主朋友 | `あたし` | — | 用来与女主形成对比，强化女主的克制 |

**硬规则**：第一人称一旦定下，全剧不得漂移。这是 AI 生成日语时最高频的错误之一，也是母语审核最容易一眼看出"这不是日本人写的"的地方。

### 敬语层级速查

| 关系 | 语体 | 例 |
|---|---|---|
| 女主 → 男主（上司） | 丁寧語＋謙譲語 | `確認いたします` |
| 男主 → 女主（部下） | 丁寧語（不用命令形） | `確認してもらえますか` |
| 反派 → 女主（同事但压制） | 前期：普通体＋命令形；后期：过剰敬語 | 前 `やっといて` → 後 `お願いできますでしょうか` |
| 全员 → 客户 | 尊敬語＋謙譲語 | `ご確認いただけますでしょうか` |
| 人事 → 女主（通知雇止め） | 最高丁寧＋事務的 | `次回の更新はございません` |

最后这一句是第1集的钩子台词。它的力量来自：语法上无可挑剔的礼貌 + 内容上不可挽回的宣告。**不要给它配愤怒的表演**，配一个礼貌的鞠躬。

## 第三部分 · 监修前自检清单

剧本交给日语母语监修**之前**，逐项自查。每挡住一条，就省一轮监修往返：

- [ ] 全剧无 `組長` 等禁用词
- [ ] 每个角色的职位在职权映射表中有明确落位，且与其行为权限一致（无权的人没做有权的事）
- [ ] 称谓矩阵全表填满，无空格，无前后矛盾
- [ ] 每个角色的第一人称全剧统一
- [ ] 反派称呼女主的分段变化点标注在具体集数
- [ ] 女主身份写明为"直接雇用の有期契約社員"，非派遣
- [ ] 雇止め场景中通知人具备正式职权
- [ ] 无"当众下跪""扇耳光""大声吵赢"等中国式冲突动作
- [ ] 威胁性台词用敬语表达，不用粗口
- [ ] 敬语层级与人物关系表一致（无下属对上司用普通体）

**这份清单的经济价值**：每挡住一轮监修往返，按 T3 计算器的监修单价区间，省 5,000–20,250 元中的约 1/2–1/3 轮次成本。它是本项目投入产出比最高的一张纸。
