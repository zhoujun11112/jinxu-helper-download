# T1 · 制作流水线 SOP（修订版顺序）

交付编号 T1 ｜ 应 ChatGPT R01 要求 ｜ 采纳其"临时音频先行、最终音频后置"的修正

---

## 顺序总览

```
①日语监修剧本 → ②临时配音 → ③animatic → ④角色与场景关键帧 → ⑤视频生成
→ ⑥粗剪 → ⑦最终配音 → ⑧选择性口型 → ⑨日文贴字 → ⑩质检
```

关键修正（对比原方案）：**画面不再最先做**。台词时长在第②步就锁死，第③步产出的 animatic 是全片的节奏母版，后续所有镜头按它的秒数生成——这样日语敬语的长句不会撞坏画面节奏。

---

## 逐环节规格

| # | 环节 | 输入 | 输出 | 责任人 | 可返工位 | go/no-go 标准 |
|---|---|---|---|---|---|---|
| ① | 日语监修剧本 | 中文日本化大纲、机制规则表、称谓矩阵 | 12集日语定稿台词（带每句预估秒数） | 双语编剧 + 日语母语监修 | 回②前可无限改；进③后改词需重做animatic | 母语监修签字：无敬语错误、无称谓漂移、无"中国式反应" |
| ② | 临时配音 | ①的台词 | 临时TTS音轨（分句文件，命名到镜头号） | AIGC制作 | 免费重跑 | 每句实际时长与脚本预估差 ≤15%；全集总时长落在 45–75 秒 |
| ③ | animatic | ②音轨 + 分镜草图/占位图 | 带音轨的节奏样带，**每镜头秒数表**（本SOP的核心产物） | 剪辑 | 免费重排 | 每12秒有新增信息/选择/风险；首个不可逆事件 ≤20秒；删任意15秒会影响理解 |
| ④ | 关键帧 | 角色定妆资产、场景底图、③的秒数表 | 每镜头首帧（必要时含尾帧），通过人工筛选 | AIGC制作 | 单帧重抽，成本低 | 见 T2 一致性盲评：同角色识别率 ≥95%，"换了演员"镜头 ≤1个 |
| ⑤ | 视频生成 | ④关键帧 + 秒数表 | 每镜头视频片段（无文字、无最终口型） | AIGC制作 | 单镜头重生成 | 画内不出现可读日文；单镜头人物一致性通过；无手部畸变 |
| ⑥ | 粗剪 | ⑤片段 + ②临时音轨 | 锁定画面结构的粗剪 | 剪辑 | 可换镜头顺序 | **画面结构锁定**（此后不再改台词，否则回②） |
| ⑦ | 最终配音 | ⑥锁定的秒数 + ①台词 | 正式日语配音（角色声音ID固定） | 配音/AIGC | 单句重录 | 逐句人工验收：无棒読み、情绪幅度符合角色卡、第一人称稳定 |
| ⑧ | 选择性口型 | ⑦音轨 + ⑤近景片段 | 口型同步后的近景片段 | AIGC制作 | 单镜头重做 | **只做近景**；中远景/过肩/背影/独白盖表情镜头一律不做 |
| ⑨ | 日文贴字 | 屏幕UI截图、文件版式、字幕 | 全部画内日文与字幕 | 剪辑 | 随时改，成本极低 | 字体为免费商用（Noto Sans JP等）；9:16安全区双平台取交集 |
| ⑩ | 质检 | 成片 | 交付母版 + 镜头台账 | 制片 + 日语母语终审 | 打回任意环节 | 见下方质检清单 |

## 三道硬门（不过不得进入下一阶段）

**门1 · 技术验收（在④⑤之间，第2–3周）**
同一角色 × 3场景 × 3镜头 + 一组正反打 + 一个近景口型。不过关就转 2.5D 风格，此时累计花费 <3,000元。

**门2 · 节奏验收（③之后）**
animatic 拿给非项目人员盲看，问"下一集想不想看"。不过关就回①改剧本——此时一帧画面都还没生成。

**门3 · 数据验收（前3集发布后）**
见 R02 的 KPI 对账表。不过关不补后9集。

## 质检清单（第⑩步逐项打勾）

- [ ] 画内无AI生成的日文残留
- [ ] 同一角色跨集发型/服装/年龄无漂移
- [ ] 声音ID与角色卡一致，第一人称全片稳定
- [ ] 称谓矩阵无违反（谁对谁用什么称呼）
- [ ] 室内脱鞋、左行驾驶、插座、门牌等视觉禁错表全过
- [ ] 字幕在 TikTok 与 YouTube 双平台安全区内
- [ ] 每集0–3秒有钩子，结尾有不可逆新问题
- [ ] BGM 来自商用曲库且留存授权凭证
- [ ] AI内容标识已按平台规则勾选
- [ ] 镜头台账完整（prompt/seed/模型版本/抽数/成本）

## 返工成本梯度（决定"能改到什么程度"）

从便宜到贵，改动应尽量往左侧推：

```
贴字/字幕  <  剪辑顺序  <  临时配音  <  关键帧  <  视频生成  <  台词改写(回②重做animatic)
  ≈0元        ≈0元        ≈0元        几元        几十元         半天工时
```

**这条梯度是SOP的经济学基础**：所有能在左侧解决的问题，绝不推到右侧。例如"这句话观众听不懂"——先试字幕改写，再试剪辑补一个反应镜头，最后才考虑重新生成画面。
