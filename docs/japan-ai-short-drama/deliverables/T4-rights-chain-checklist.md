## 第一部分 · 权利链溯源（填不满就不要签）

短剧的权利链通常有 3–4 层，断在任何一层，你拿到的授权都是空的。

| # | 环节 | 权利人 | 证明文件 | 状态 |
|---|---|---|---|---|
| 1 | 原始小说/漫画/网文 | | 著作权登记证 / 平台签约合同 | ☐ 已核 ☐ 缺失 ☐ 不适用 |
| 2 | 短剧剧本（改编自1） | | 编剧合同、委托创作协议、著作权归属条款 | ☐ 已核 ☐ 缺失 |
| 3 | 短剧成片（制作方） | | 摄制合同、出品方约定、演员肖像授权 | ☐ 已核 ☐ 缺失 |
| 4 | 平台独家（若有） | | 平台独家协议及其地域/期限范围 | ☐ 已核 ☐ 无独家 |
| 5 | 音乐/字体/素材 | | 第三方素材授权是否可转授 | ☐ 已核 ☐ 缺失 |

**高危信号**（出现任一项，暂停谈判）：
- 对方只能提供成片权属，说不清剧本权属
- 原著作者与剧本方存在未了结的分成争议
- 平台独家条款覆盖"全球"或"海外"，而对方声称可以单独授日本
- 对方要求你自行承担第三方索赔

## 第三部分 · 人格权专项（我在 R01 的表述需要修正）

我在 R01 建议合同加入"著作者人格权不行使特约"。ChatGPT 反驳说这不能作为一句模板套用——**这条反驳成立**，我修正如下：

问题的实质是：深度本地化必然大幅改动原作（改国籍、改职业体系、改家庭结构、改冲突方式），这在中国法下可能触及**保护作品完整权**，在日本法下对应**同一性保持权**。这两项都属人格权，与财产权不同，其可否放弃/不行使、放弃条款的效力边界，中日两地的制度设计与司法实践并不相同。

**因此正确做法不是套模板，而是把它列为必须请律师专门设计的条款**，并在谈判时先取得两项事实：

1. 版权方是否已从原著作者处取得足以支持"再改编"的授权（而不只是拍这一部的授权）
2. 版权方能否代原著作者作出改编幅度的承诺，还是必须回溯到原著作者本人签字

第 2 点决定谈判周期。如果必须回溯到原著作者，21 天的谈判目标基本不可能达成——这直接关系到 R02 中我对"授权改编会否拖死验证"的攻击。

## 第五部分 · 非版权类合规（试产期即需建立）

| 项目 | 基线做法 |
|---|---|
| 声音 | 只用平台官方商用授权声库；**禁止真人音频克隆**；禁止以"像某声优"作卖点；留存授权版本与使用范围记录 |
| 肖像 | 定妆图完成后做反向图搜自查，避免撞脸日本艺人；prompt 中禁止出现任何真人姓名 |
| 音乐 | 商用曲库订阅（含日本本土曲库）；不使用来源存疑的AI生成音乐 |
| 字体 | 免费商用安全线：Noto Sans JP / 源ノ角ゴシック / M+ 系 |
| 商标与商号 | 片中公司名、产品名、logo 全部虚构，并做一次注册商标检索 |
| AI 标识 | 按平台规则主动标注；对外以"AIショートドラマ"厂牌定位，不隐瞒 |
| 投放合规 | 景品表示法 + ステマ规制：投放素材中的"用户好评"必须真实 |
| 未成年人 | 涉未成年人形象从严，第一部建议直接回避 |
