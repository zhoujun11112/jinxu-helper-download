# 日本市场AI短剧本地化与流水线制作方案（讨论稿·原文存档）

> 本文件为原始讨论稿的存档，供评审报告（见 `01-adversarial-review.md`）对照引用。

## 一、项目目标

计划将国内已有短剧剧本，在取得合法授权的前提下，改编为适合日本市场观看的竖屏短剧。

本项目不是简单进行中文翻译，而是完成以下四项工作：

1. 将中国故事逻辑改造成日本社会语境下成立的故事；
2. 将人物、职业、家庭关系、场景和冲突方式进行日本本土化；
3. 使用AI完成剧本拆解、分镜、角色设定、视频生成、配音和字幕；
4. 建立一条可以不断复制、降低成本的半自动短剧制作流水线。

核心目标是：先用较低成本验证日本观众是否接受，再决定是否扩大生产规模和建设完整系统。

## 二、核心判断

### 1. 现阶段不建议先购买高端电脑

日本短剧流水线涉及三类核心资产：剧本本地化引擎、日本文化知识库、角色与场景资产库。

这三部分本身并不依赖高性能显卡，主要依赖：大模型API、数据库、文件存储、工作流调度、人工审核。

真正消耗显卡算力的是：图片生成、视频生成、口型同步、高清修复、人物动作生成。这些环节前期可以全部使用云端服务。

推荐电脑配置：32GB内存；1TB或2TB NVMe固态硬盘；普通CPU；能够完成常规剪辑的显卡即可；稳定的高速网络；配套网盘或对象存储。

只有当每月云端视频生成费用长期高于本地设备折旧、电费和维护成本时，再考虑购买高显存工作站或GPU服务器。

### 2. 市面上有现成工具，但没有真正完整的一站式方案

**剧本、分镜与制片管理**：PopShort、LTX Studio、其他AI短剧和AI分镜平台。主要功能：上传剧本、自动提取角色场景道具、生成分集结构、生成镜头脚本、生成角色设定、管理可重复使用的角色资产。

**视频生成**：可灵、Vidu、Runway、其他支持参考图和角色一致性的AI视频平台。适合：每个镜头单独生成、使用角色参考图、使用首尾帧、保持固定服装和场景、生成5至8秒的短镜头。不建议让AI一次直接生成完整一集。

**日语配音**：ElevenLabs、日本本地AI语音平台、真人配音和AI语音混合方案。配音时要固定：角色声音ID、年龄、语速、第一人称、敬语层级、情绪幅度、对不同人物的称呼。

**自动化流程**：n8n、Dify、自建轻量后台。主要用于：自动拆解剧本、调用多个AI平台、文件命名、任务流转、审核、失败重试、状态记录、成本统计。

目前市场上有"零部件"和"接近一站式的平台"，但还没有一款产品能够稳定完成：中国剧本导入 → 日本文化重构 → 日本人物和社会关系重构 → 连续多集人物一致的视频 → 合格日语对白 → 自动成片。

因此最现实的模式是：70%使用现成云端工具，30%建设自己的本地化规则、资产库和审核流程。

## 三、日本版不能只做翻译

最容易失败的做法是：中国姓名换成日本姓名、人民币换成日元、北京换成东京、中国演员脸换成日本演员脸、中文台词直接翻译成日语。

这样做出来的内容，本质上仍然是"中国剧情穿了一套日本外衣"。

真正需要改造的是：社会关系、职业体系、家庭结构、冲突表达、权力距离、敬语、人物情绪、审美风格、生活场景、法律与伦理逻辑。

## 四、中国短剧元素向日本市场的改编方向

| 中国短剧元素 | 日本化建议 |
| --- | --- |
| 霸道总裁 | 大企业精英部长、创始家族继承人、医院继承人、老字号少东家 |
| 豪门家族 | 企业创始家族、地方名门、京都传统家族、医疗集团、老字号家族 |
| 彩礼矛盾 | 婚礼费用、家庭背景、父母反对、继承条件、婿养子 |
| 婆媳大战 | 同居压力、育儿观念、家庭边界、表面礼貌下的排斥 |
| 京城第一家族 | 银座老字号、京都传统家族、财团创始家族、地方医疗集团 |
| 当众扇耳光 | 会议揭露、录音曝光、内部审计、辞职、调职、记者会谢罪 |
| 跪地求饶 | 正式谢罪、辞职、降职、调离、公开道歉 |
| 门当户对 | 家庭背景、学历、职业稳定性、家族继承、社会身份 |
| 契约婚姻 | 家庭催婚、继承条件、住房问题、公司利益、家族安排 |
| 重生复仇 | 时间回溯、人生重启、梦境警示、掌握未来信息 |
| 战神归来 | 海外归国精英、隐退企业家、匿名核心技术人员 |
| 神医题材 | 医院继承、医疗事故、研究成果、专业身份反转 |

核心原则：保留中国短剧的爽点，但改变爽点的表达方式。

中国短剧常见的是直接冲突、公开羞辱和快速打脸。日本版更适合：情绪克制、信息逐步揭露、表面礼貌、内心博弈、证据反转、社会性后果、职场处分、公开谢罪。

## 五、推荐优先测试的日本短剧题材

**方向一：职场身份反转**。示例：被公司辞退的合同员工，实际上是公司核心专利的匿名开发者。优点：场景少、人物少、服装稳定、容易保持角色一致性、日本职场环境天然适合身份反转和压抑后的爆发、AI制作成本较低。主要场景：办公室、会议室、咖啡店、女主公寓。

**方向二：婚姻背叛与克制复仇**。示例：全职主妇发现丈夫长期转移财产，但没有立即摊牌，而是重新工作、收集证据并逐步夺回人生。日本化重点：不使用连续争吵和扇耳光；强调表面维持婚姻、暗中调查；通过证据、财产、工作和社会关系完成反转；让女主的成长比单纯报复更重要。

**方向三：老字号继承悬疑**。示例：女主回到京都参加祖母葬礼，意外成为百年和果子店继承人，却发现家族成员都在隐瞒一场旧案。优点：日本地域文化辨识度强、可结合家族继承爱情和悬疑、场景具有视觉吸引力、有利于差异化。风险：对建筑服饰礼仪和传统行业的准确性要求更高、AI生成错误更容易被日本观众发现、不适合作为第一部低成本测试剧。

## 六、建议的第一部样片

暂定项目名：《被开除的她，是公司的匿名王牌》。类型：职场逆袭＋身份反转＋轻爱情。

**女主**：29岁；东京中型科技公司合同员工；性格安静、专业、克制；实际上是公司关键算法的匿名原作者。

**男主**：34岁；新任开发本部长；理性、谨慎；初期对女主身份产生怀疑，后期成为支持者。

**反派**：正式员工女组长；重视身份和内部等级；抢夺女主成果；利用合同员工身份压制女主。

**辅助人物**：公司老员工、人事负责人、客户方技术代表、女主朋友。

**固定场景**：办公区、会议室、女主公寓、咖啡店。

**试验规模**：12集；每集45至75秒；总时长约12分钟；4个主要人物；3至4个固定场景；每集结尾必须设置悬念；第3集完成第一次身份暗示；第6集完成第一次大反转；第12集完成核心反转并留下第二季入口。

## 七、日本版剧本流水线

国内授权剧本 → AI提取核心情节、爽点和人物关系 → 判断哪些内容不能直接进入日本市场 → 重新设计日本人物、职业、家庭和场景 → 生成中文版日本化剧情大纲 → 生成日语剧本初稿 → 日本母语人员审核 → 修改敬语、称谓、社会逻辑和台词 → 生成分集剧本 → 生成镜头脚本 → 建立人物、服装、场景和道具资产 → 逐镜头生成视频 → 日语配音 → 字幕、音效和剪辑 → 日本母语人员终审 → TikTok、YouTube Shorts等渠道测试 → 根据数据决定扩集或重制

## 八、日本文化知识库不需要一开始做得很大

前期只建立与第一部项目直接相关的六类规则：

1. **人物关系表**：上司与部下、前辈与后辈、正式员工与合同员工、夫妻、未婚夫妻、婆媳、客户与供应商。
2. **称谓和敬语表**：姓＋さん、姓＋部長、姓＋課長、先輩、先生、君、ちゃん、あなた、第一人称的选择。要明确每个角色对不同人物的称呼，避免前后混乱。
3. **日本职场规则表**：公司层级、部长课长主任等职位关系、合同员工与正式员工差异、会议礼仪、名片交换、调职、辞职、内部处分、谢罪、加班、年功序列、内部审批。
4. **家庭关系表**：婚姻、同居、继承、婿养子、家庭登记、东京与地方差异、与父母同住、家族企业。
5. **场景表**：日本公寓、独栋住宅、办公室、会议室、居酒屋、便利店、医院、老字号店铺、通勤电车、咖啡店。
6. **视觉禁错表**：室内是否脱鞋、汽车左右驾驶、日本道路方向、插座样式、办公室工牌、住宅玄关、门牌、便利店陈列、餐具、校服、日文文字、公司职位牌、日元纸币与硬币。

知识库的价值不是介绍日本文化，而是：防止AI在批量生产中不断犯同样的低级错误。

## 九、角色资产库设计

每个主要角色建立一份固定角色卡。建议字段：角色ID、日文姓名、年龄、身高、体型、发型、发色、面部特征、职业、职位、性格、第一人称、对其他角色的称谓、敬语级别、声音ID、语速、情绪幅度、常用服装、不同场景服装、禁止变化项、禁止用语、角色正面图、侧面图、全身图、表情图、角色参考视频。

每一个场景也应建立固定资产：场景ID、位置、空间布局、墙面颜色、桌椅、灯光、门窗、道具、镜头方向、禁止变化项。

## 十、日语母语审核是必要环节

AI可以完成日语初稿，但不能完全替代日本本土人员。审核人员主要负责检查：日本人是否会这样说、敬语是否正确、职位关系是否合理、上下级说话方式是否准确、第一人称是否稳定、称谓是否前后一致、家庭行为是否符合日本社会习惯、角色反应是否过于中国化、是否存在明显文化错误、是否存在容易引起反感的内容、日文字幕是否自然、配音节奏是否像翻译腔。

前期可以寻找：日本母语兼职编剧、在日留学生、有影视经验的日语编辑、日本内容运营人员、日本短视频创作者。

核心要求不是"日语考试成绩高"，而是：能判断日本观众看了会不会觉得假。

## 十一、视频生成建议

**不建议一次生成完整一集**。一集60秒建议拆成8至12个镜头，每个镜头约3至8秒，单独生成，后期剪辑。

镜头类型包括：建立镜头、人物中景、近景、表情特写、手部动作、手机屏幕、文件证据、反应镜头、结尾悬念镜头。

**人物一致性原则**：每一个镜头都必须绑定角色参考图、固定服装、固定发型、固定场景、固定光线、固定年龄、固定身体比例、固定声音。

尽量避免：人数过多、高频换装、群体打斗、复杂舞蹈、大规模外景、人群穿梭、长时间连续对白、同一镜头出现过多人物。

## 十二、前期测试策略

第一阶段不做完整60至80集。先制作3集概念样片或12集短测试版。

测试重点：日本观众是否愿意继续观看、前3秒是否能够留住观众、第1集完播率、第2集跳失率、第3集追更率、评论中是否出现"不像日本人"的反馈、AI人物是否令人出戏、日语是否有翻译腔、每分钟实际制作成本、每集平均返工次数、哪些镜头最容易失败、哪类情节更容易产生分享和评论。

不要只看播放量，要重点看：3秒留存、10秒留存、完播率、下一集点击率、评论情绪、关注转化、每个镜头成本、每分钟成片成本、人工返工时间。

## 十三、实施阶段建议

**第一阶段：人工调用现成工具**。目标：跑通一部3集或12集样片；暂时不建设完整后台；人工完成文件传递和审核；测算真实成本。

**第二阶段：半自动流水线**。将以下环节自动化：剧本导入、人物关系提取、日本化改写、敏感内容检查、分集、分镜、提示词生成、文件命名、配音任务、字幕任务、审核流转、成本统计。

**第三阶段：形成平台**。当已经验证：日本用户愿意观看、某类题材能够持续获得留存、每分钟成本可控、AI人物一致性可接受、本地化审核流程稳定；再建设：剧本本地化引擎、日本文化知识库、角色资产管理系统、多项目生产后台、任务调度系统、成本与数据分析系统。

## 十四、版权和合规原则

任何国内已有短剧剧本，如果保留了核心人物关系、主要剧情结构、关键反转、标志性情节、原创对白、角色设定，即使改了姓名、国家和场景，也可能属于改编作品。

因此建议优先采用：正式购买海外改编权、与版权方进行联合出海、购买剧本使用权、使用原创剧本、只借鉴通用类型结构不复制具体情节。

AI改写不能自动消除版权风险。

日本市场还需要特别关注：肖像权、声音克隆授权、音乐版权、字体版权、商标、未成年人形象、虚假广告、平台AI内容标识要求、暴力性恐怖和不伦内容尺度。

## 十五、当前明确建议

现阶段不建议：购买昂贵显卡工作站、建设大型平台、同时做多个国家、一开始制作60至80集、完全依赖AI日语、直接翻译中国短剧、一次生成完整剧集。

建议先做：一部日本职场身份反转短剧，12集，每集约60秒，4个主要角色，3至4个固定场景。

推荐起步组合：大模型（剧本拆解与日本化初稿）、日本母语人员（文化和日语审核）、LTX或类似平台（人物场景与分镜）、可灵Vidu或Runway（逐镜头生成）、ElevenLabs或日语语音平台（配音）、剪映或Premiere（剪辑与字幕）、n8n或Dify（后期自动化）。

核心验收标准不是画面是否华丽，而是：日本观众看起来，是否像一个真正发生在日本的故事，而不是中国短剧的日语翻译版。

## 十六、希望共同讨论的问题

1. 日本短剧市场目前最值得切入的题材是什么？
2. "职场身份反转"是否适合作为第一部测试剧？
3. 第一部应该制作3集、12集，还是直接制作30集？
4. AI真人风、动画风和真人拍摄，哪一种更适合日本市场验证？
5. 日本观众对AI人物和AI配音的接受度如何？
6. 哪些中国短剧冲突在日本市场最容易水土不服？
7. 日本版剧本最需要本地人员审核的环节是什么？
8. 是否有比PopShort、LTX、可灵、Vidu、Runway更适合的现成平台？
9. 日本本地是否已有成熟的短剧制作SaaS或内容发行渠道？
10. 日本短剧的合理单集长度、集数和付费模式是什么？
11. 首批流量测试应优先选择TikTok、YouTube Shorts、Instagram Reels还是本土平台？
12. 一分钟AI短剧的合理制作成本应该控制在什么范围？
13. 哪些步骤适合自动化，哪些步骤必须保留人工审核？
14. 如何建立稳定的人物一致性和日语声音一致性？
15. 是否应该优先购买国内剧本版权，还是直接创建原创日本剧本？
16. 日本市场可能遇到的版权、声音、肖像、音乐和平台合规风险有哪些？
17. 这套方案中是否存在明显低估的成本、技术难点或市场风险？
18. 请给出一个更低成本、更快验证的替代方案。

评审要求：不只评价工具功能，从日本市场适配、内容质量、技术可行性、制作成本、商业闭环五个维度，分别扮演日本编剧、制片人、技术负责人、版权顾问和平台运营负责人，对方案进行对抗式评审。
