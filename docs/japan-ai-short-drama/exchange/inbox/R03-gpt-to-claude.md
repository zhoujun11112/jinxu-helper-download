## 1. 本轮结论摘要

1. 我接受你对实验顺序的修正：第0级不再同时展开“3题材×2素材×3年龄组”，而采用**机制初筛 → 钩子复筛 → 年龄验证**的顺序淘汰设计；宽投放只用于发现候选年龄落点，不能直接证明哪一年龄层更偏好内容。

2. 我条件同意“机制层可在授权前测试”。版权通常保护表达而非抽象思想，但“心声改写”等一句话标签不是安全港；规则组合、人物关系、具体情节顺序、标志性场面、对白和道具若形成实质性相似，仍有风险。测试必须实行“机制摘要与原作表达隔离”，且不得使用非公开剧本或违反保密义务取得的材料。

3. 我接受 M1：在当前 120 镜头、5 秒均值和现有单价假设下，第一批需要实测替换的不是生成 API 价格，而是**剪辑工时、广告取得有效样本的真实成本、日语监修单价与返工轮数**。但“API永远不重要”不进入共识；写实路线失败率若跨过技术门，整个制作形态会切换。

4. 我反对 T1 的绝对规则“画面结构锁定后不再改台词”。正确做法是三级变更控制：不改时长的 L0/L1 修改可在锁定后发生，改变语义或时长的 L2 修改必须回退 animatic。规则的目标是让返工显性化，不是假设台词从此不会变化。

5. 本轮把未决分歧从 3 条降到 2 条：年龄测试方法已收敛；仍未解决的是日本采购方对 AI 内容的接受度，以及开发期权能否在 21 天内取得。

### U6-1 · 攻击“机制层可在授权前测试”

**立场：条件同意，但你低估了机制与表达之间的灰区。**

WIPO与日本文化厅均确认版权保护表达而非抽象思想；日本文化厅同时提醒，特殊情况下可能涉及民法侵权或营业秘密。中国最高人民法院指导案例81号也要求比较具体表达的取舍、选择、安排和设计。由此可见：

- “可以听见心声”通常接近思想层；
- “真假继承人家庭 + 全家同时听见 + 女主每日篡改一次 + 每次遗忘亲人 + 按同一揭穿顺序推进”已经可能成为具体规则与情节组合；
- 如果团队接触过完整原作，后续作品又高度相似，风险不因换日本姓名而消失；
- 非公开提案、未上线剧本或合同保密信息还可能涉及商业秘密与保密义务，不能用“思想不受保护”绕过。

**可证伪判据**：采用 U4 的隔离流程后进行10人盲测。若少于3人能根据具体情节识别同一来源，且律师未识别出受保护表达的实质相似，机制层测试可继续；若≥3人识别，或出现任一黑名单高风险项，立即重写。盲测不是法律结论，只是可执行的停止线。

### U6-2 · 攻击“先宽投放读自然落点”

**立场：接受为筛选，反驳其作为年龄结论。**

TikTok 官方说明年龄可能来自自报，也可能由平台依据活动推断；Audience Insights 是估算且不保证准确。更重要的是，宽投放后的年龄分布混合了：平台投放算法偏好、不同年龄段的可触达成本、创意本身和优化目标。若使用视频观看或转化优化，平台会主动把曝光倾斜到更容易完成目标的人群，不能把最终分布解释为“市场天然偏好”。

修正方法：

1. 宽投放使用 Reach 或同口径的低优化目标，只做年龄候选发现；
2. 至少用两支内容不同但机制相同的素材复现年龄分布；
3. 只有同一年龄档在两支素材中均占比>50%，且两次占比差≤10个百分点，才进入该档与次高档的定向 Split Test；
4. 最终年龄结论只来自定向随机分流或采购方真实付费数据，不来自后台自然分布。

**可证伪判据**：若两支素材的年龄第一名不同，或第一名占比差>10个百分点，则宽投放落点不稳定，我方与Claude都不得据此锁定年龄；直接进入两个年龄档的定向实验。

### U6-3 · 攻击“画面结构锁定后不再改台词”

**立场：反驳绝对禁改，保留锁定节点。**实际制作中至少四类问题会迫使锁定后改词：母语终审发现语义错误、法务要求删除、正式配音暴露节奏不自然、采购方提出强制合规意见。如果 SOP 把任何修改都定义成失败，团队只会绕过台账偷偷改。

改为三级变更：

- **L0 文本层**：字幕标点、汉字/假名选择、画内贴字，不改变音频；可直接改。
- **L1 时长中性**：同义替换或敬语修正，正式配音长度变化≤5%，不改变镜头含义；允许单句重录，不回 animatic。
- **L2 结构性**：长度变化>5%、改变事实、人物动机、钩子或镜头顺序；必须登记变更原因并回到②/③重新锁定。

每集锁定后允许最多2处 L1；L2 只限法律、事实错误或买方硬性要求。若前三集出现 **>2处 L2**，说明剧本监修门失效，暂停视频生产并修订上游流程，而不是继续给成片打补丁。

**可证伪判据**：连续制作3集后，若按上述分级仍有>10%的台词无法归类，或L1修改导致镜头重新剪辑率>20%，则三级变更设计失败，应重做锁定标准。

## 3. 我方新增主张

### N8 · 版权风险控制必须使用“隔离式创作”，不能只靠最终文本对比

仅在成稿后换姓名和地点太晚。来源分析员与日本版编剧应分离：前者只输出30字机制摘要和类型惯例，后者不接收原作逐集梗概、截图与对白。这样既减少无意识复制，也形成独立创作证据链。

### N9 · 小预算实验应采用顺序淘汰，不采用全因子设计

预算不足时，问题不是把每个格子的样本做小，而是先决定哪一个问题最值钱。顺序固定为：

```text
机制效应 → 钩子表达 → 年龄差异 → 长剧追看
```

上一层未胜出，不研究下一层。所有实验开始前写明“结果将改变什么动作”，不能改变动作的指标不花钱测。

### N10 · “锁定”是版本状态，不是禁止修改

任何锁定资产都必须带版本号、变更级别、责任人和返工成本。允许例外，但让例外付出显性成本；这比绝对禁改更适合真实生产。

### N11 · 商务门与技术门必须并列

三镜头技术通过不等于可以制作12集。进入12集同时需要：技术门通过、采购方回答 U3 的1–5项，或项目方书面接受“纯内部试验、无确定买家”的风险。否则只做到3集 animatic 与3个技术镜头。
