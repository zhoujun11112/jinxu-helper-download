# EP01 配音投放目录

把配好的日语语音文件按下表命名放进本目录，然后跑：

```bash
FFMPEG_BIN=<你的ffmpeg> python3 tools/make_ep01.py
```

脚本会**自动按时间码混入**，不需要手动对齐。心声轨会自动降 3dB（听起来更"远"），与音频设计文档一致。
缺哪句就少混哪句，其余照常出片——可以先配两句试听。

## 配音要求

**三个声音 ID 选定后全剧不换**，写进角色卡。

| 角色 | 第一人称 | 语速 | 音域 | 情绪幅度 | 备注 |
|---|---|---|---|---|---|
| 女主 | 私（わたし） | 偏慢 | 中低 | 小 | 独白可略放开，台词必须克制 |
| 人事課長 | 私 | 中 | 中低 | **极小** | 通知雇止め时**不要带愧疚**，越事务性越冷 |
| 係長 | 私 | 略快 | 中 | 小但锋利 | 心声里的轻蔑不靠音量，靠语速 |
| 母 | — | 慢 | 中高 | 温和 | 日常口吻，不要演"感人" |

**b01 是全片最重要的一句**：语法上无可挑剔的礼貌，内容上不可挽回的宣告。配音要平、要礼貌、**不要有任何歉意**——歉意会削弱它的残酷。

**b15 母亲那句**要配得越日常越好。它的力量来自女主认不出这个声音，母亲本人毫无异常。
